# 🚀 Práctica de Git

[![Git](https://img.shields.io/badge/Git-F05032?style=for-the-badge&logo=git&logoColor=white)](https://git-scm.com/)
[![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=for-the-badge&logo=typescript&logoColor=white)](https://www.typescriptlang.org/)

Guía rápida de los comandos básicos para inicializar y guardar cambios en el repositorio local.

---

## 📌 1. Crear el Proyecto e Inicializar Git

Para inicializar el control de versiones en la carpeta del proyecto:

```bash
git init
```

---

## 💾 2. Guardar los Cambios

Para preparar los archivos modificados y registrar el commit:

```bash
# Agregar todos los archivos al área de preparación (staging)
git add .

# Guardar los cambios con un mensaje descriptivo
git commit -m "feat: setup inicial y variables globales"
```

---

> [!TIP]
> Puedes verificar el estado de tus archivos antes y después de cada paso con:
> ```bash
> git status
> ```
